# AI Care Alert

## The Problem

Every day, people living alone face a silent risk.

A fall. A sudden health episode. A moment where they need help 
but cannot reach anyone. For elderly people, disabled individuals, 
and those managing long term conditions — this is not a hypothetical. 
It is a daily reality.

Current solutions exist but they have gaps. Most require the person 
to press a button — which assumes they are conscious and able to react. 
Many connect to paid monitoring centres rather than the people who 
actually care about them. And almost none are intelligent enough to 
tell the difference between a real emergency and a false alarm.

This project explores a different approach — a system that combines 
a manual alert option with automatic AI-based monitoring, so that 
help can be triggered whether or not the person is able to ask for it.

Built for people who live alone. For families who worry. 
For a gap that technology has not yet properly filled.
